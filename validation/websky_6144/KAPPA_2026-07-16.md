# CMB lensing convergence κ from halos (2026-07-16) — first Tier-B test

First painting-level check from the Stein+2020 plan: Born-approximation **halo-only** κ maps
painted identically from both catalogs (point-mass per halo, CMB source plane), matched
footprint = 7.08° square inscribed in the shared 5° cap, gnomonic flat-sky, 512² pixels,
M>2e12, r=50–5150 Mpc/h. Script: `compare_kappa.jl`. Catalog counts in footprint:
404,760 (ours) vs 395,779 (Websky) — 2.3% apart, consistent with the MF match.

## Key methodological lesson (why raw ours/wsky ≠ 1 is NOT a failure)

Raw high-ℓ C_ℓ converges to each catalog's **halo shot noise** (ours 1.31e-9, Websky
2.31e-9; the raw ratio plateaus at ~0.56 = the shot ratio). Shot is dominated by the few
*nearest massive halos* — a realization-dependent quantity — and our octant vs Websky's
patch are **different sky**. Unlike ξ(r)/b(M)/v12(r) (ensemble clustering statistics that
matched to a few %), the raw C_ℓ of a single 5° cap is not an ours-vs-Websky test. The
meaningful pass criterion is each catalog against the Limber prediction, as above.

## Architecture decision for full κ (recorded 2026-07-16)

Websky's released `kap.fits` (paper §3.2.3) = resolved-halo NFW pasting (c=7, ρ∝r⁻² to
2r200, kernel `W_Kappa` — implemented in Fortran `pks2map` profile code `kap`) + **field
matter** from LPT-displaced particles minus halo mass (⟨κ⟩=0) + a z>4.5 Gaussian Limber
tail. Plan:
- **Halo κ painting → contribute a lensing model to XGPaint.jl** (the extragalactic
  painting reference; currently has no lensing). Fits its catalog→map design; PeakPatch.jl
  keeps its "painting is XGPaint's job" boundary.
- **Field-matter/mass-shell lightcone output → new PeakPatch.jl feature** (only the
  simulation side has the LPT fields; same split as Fortran). Also needed for the kSZ
  field component (paper Fig 6) — one feature, two figures.
- z>4.5 tail: trivial script.
